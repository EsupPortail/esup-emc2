# Version 5.6.1 (XX/XX/2026)

## Changements 

[CORRECTION]
* Utilisation de l'adresse complète pour la recherche d'utilisateur pour éviter le plantage de la recherche pour certains établissements
* Correction de l'import depuis le format de Fiche Métier qui dupliquait certaines activités/familles professionnelles/missions
* Adaptation au changement de format des identifiants des compétences du référentiel REFERENS3 (0067 => 67)
* Le dernier paramètre (isAllowed) de la méthode printReference est maintenant optionnel
