## Modification des données

```postgresql
INSERT INTO unicaen_privilege_privilege(CATEGORIE_ID, CODE, LIBELLE, ORDRE)
WITH d(code, lib, ordre) AS (
    SELECT 'ficheposte_ajouter_pdf', 'Ajouter une fiche de poste au format PDF', 200
)
SELECT cp.id, d.code, d.lib, d.ordre
FROM d
JOIN unicaen_privilege_categorie cp ON cp.CODE = 'ficheposte';

```

## Évolution de la liste des privilèges

Nouveau privilège pour différentier le dépôt des fiches de poste aux formats PDF
- `ficheposte_ajouter_pdf` : Fiche de poste > Ajouter (au format PDF) 
Il est nécessaire de l'affecter aux rôles pouvant faire le dépôt de telles fiches (Recommandation à minima Administrateur·trices, Supérieur·es, Autorité·s et Responsables).

Attention : le dépôt de PDF suppose d'avoir les privilèges permettant de déposer des fichiers (UnicaenFichier).
