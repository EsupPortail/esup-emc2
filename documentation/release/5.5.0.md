# Version 5.5.0 (XX/XX/2026)

## Changements 

[CORRECTION]
* Lors de l'import de fiche métier les activités et missions sont seulement recherchées dans le même référentiel que la fiche métier
* Les spécialités sans agents ne remontaient pour la création de fiche métier

[AMÉLIORATION]
* Ajustement des certains écrans de la bibliothèque de gestion des templates
* Ajustement de l'affichage de l'index des niveaux de maitrise
* Correction de typos et simplification de texte
* Modification de libellé sur la page d'entretien (date d'entretien, envoi de la convocation)
* Réorganisation des colonnes de l'index des spécialités
* Changement du filtre de recherche des Agent·es
* Ajustement de la longueur des titres du menu 'Autres gestions'
* Blocage de la possibilité de déclarer deux exceptions ayant le même périmètre
* Ajout d'un filtre structure dans la partie exceptions

[NOUVEAUTÉ]
* Ajout d'une page de gestion des contacts
* Ajout des colonnes 'Supérieur·es hiérarchiques direct·es' et 'Autorités hiérarchiques' dans l'exportation des fiches de postes depuis la structure
* Possibilité de forcer l'obligation d'un entretien professionnel pour un·e Agent·e dans une structure dans laquelle iel n'est pas affecté·e

[PRÉPARATOIRE]
* Début de l'extraction de la partie emploi-type du grade des agents
 
## Changement de structure de la base de données

### Sans BddAdmin

```postgresql

-- Nouvel table pour stocker les emploi-types des agents
create table agent_carriere_emploitype
(
    id            integer                 not null,
    agent_id      varchar(40)             not null,
    emploitype_id integer                 not null,
    date_debut    date,
    date_fin      date,
    source_id     varchar(128),
    id_source     varchar(100),
    created_on    timestamp default now() not null,
    updated_on    timestamp,
    deleted_on    timestamp
);
```

## Évolution des synchronisations

Nouvelles données sources à synchroniser qui va exploiter une vue V_EMC_AGENT_EMPLOITYPE.
Cette vue contient les données relatives aux emploi-types associées aux agents.

```php
'AGENT_EMPLOITYPE' => [
    'order' => 5250,
    'source' => 'SIRH',
    'orm_source' => 'orm_octopus',
    'orm_destination' => 'orm_default',
    'table_source' => 'V_EMC2_AGENT_EMPLOITYPE',
    'table_destination' => 'agent_carriere_emploitype',
    'correspondance' => [
        'id' => 'id',
        'agent_id' => 'agent_id',
        'emploitype_id' => 'emploitype_id',
        'date_debut' => 'date_debut',
        'date_fin' => 'date_fin',
    ],
    'id' => 'id',
],
```
